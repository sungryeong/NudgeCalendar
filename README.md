# NudgeCalendar 🐾

노트북을 켤 때마다 화면 위를 돌아다니며 오늘 할일을 알려주는,
나만의 작은 데스크톱 리마인더 서비스 입니다

할일을 적어놔도 앱을 안 열어보면 잊어버리잖아요.
그래서 부팅할 때마다 눈앞에 나타나고, 화면 한 켠을 걸어 다니다가
멍하니 있으면 슬쩍 말을 걸어주는 캐릭터를 만들고 있어요.
옆에서 같이 있어주는 느낌으로요.

## 이런 걸 할 수 있어요

- 📅 캘린더에서 날짜를 클릭해 할일 입력
- ⏳ 오늘의 할일을 직관적으로 보여줌
- 💬 일 하고 있을때 귀여운  캐릭터가 말 걸어줌

## 사용 스택

`Electron` · `Node.js` · `JavaScript` · `HTML/CSS`
`Supabase` · `keytar` · `date-fns` · `electron-builder`
