# NudgeCalendar 기획 개요

## 왜 만들었나요

할일을 적어놔도 앱을 열어보지 않으면 잊어버리고
알림은 뜨는 순간 무시하기 쉽습니다.

그래서 화면 위에 항상 존재하면서
슬쩍슬쩍 신경 쓰이게 만드는 방식을 고민하게 됐습니다.

## 어떤 프로젝트인가요

- 날짜 기반으로 할일을 기록하고 관리하는 개인용 리마인더
- 컴퓨터를 켤 때마다 눈에 보이는 위치에 오늘 할일이 떠 있음
- 화면 한 켠을 돌아다니는 작고 귀여운 캐릭터가 함께함
- 사용자가 오래 반응이 없을 때 부담스럽지 않은 방식으로 신경 쓰이게 함
