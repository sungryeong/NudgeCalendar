# NudgeCalendar 진행 상황

이 프로젝트가 지금 어디까지 왔는지 편하게 보여주기 위한 페이지입니다.
자세한 개발 내역은 다루지 않고, 큰 흐름만 담았습니다.

## 지금까지 만든 것

- 캐릭터 디자인
- 앱의 기본 틀 마련, 실행 확인 완료
- 데이터를 저장하고 불러오는 기본 연결 확인 완료
- 캘린더에서 날짜별로 할일을 입력하고 저장하는 화면 완료
- 화면 구성을 일관되게 유지할 수 있도록 디자인 기준 정리
- 화면 사이를 더 쉽게 오갈 수 있도록 이동 구조 개선
- 할 일을 이어서 관리할 수 있는 흐름 구현

## 지금 하고 있는 것

- 할 일 완료 관리 흐름의 실제 사용 확인을 준비하는 중
