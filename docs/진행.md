# NudgeCalendar 진행 상황

이 프로젝트가 지금 어디까지 왔는지 편하게 보여주기 위한 페이지입니다.
자세한 개발 내역은 다루지 않고, 큰 흐름만 담았습니다.

## 지금까지 만든 것

- 캐릭터 디자인
- 앱의 기본 틀 마련, 실행 확인 완료
- 데이터를 저장하고 불러오는 기본 연결 확인 완료
- 캘린더에서 날짜별로 할일을 입력하고 저장하는 화면 완료

## 지금 하고 있는 것

- 할일마다 마감 시점을 알아보기 쉽게 표시해주는 기능을 다듬는 중
- 날짜와 할일을 한눈에 살펴볼 수 있도록 화면 디자인을 정리함
- 화면과 기본 기능, 개발 확인 흐름을 준비하며 하나씩 다듬는 중
